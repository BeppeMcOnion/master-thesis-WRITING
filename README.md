2. COMPILATION WORKFLOW
------------------------------------------------------------------------
To compile the final LaTeX manuscript:
1. Ensure the bibliography (.bib) is synchronized from Zotero.
2. Run the build chain using Biber for bibliography processing:
   - pdfLaTeX (1x)
   - Biber (1x)
   - pdfLaTeX (2x)
